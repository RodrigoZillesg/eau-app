Update
Unfortunately, it will not be possible to automatically import activities and certificates from OpenLearning into our system. The OpenLearning API allows for:

Automatic member registration
SSO (automatic login)
Course listing
These three functionalities will be available in our platform. However, importing user data and completed course information is not supported by their API.

We’ve followed all documentation and tested multiple approaches, but the OpenLearning endpoints that should enable this functionality are currently offline and non-functional.
